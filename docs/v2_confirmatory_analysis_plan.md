# V2 confirmatory analysis plan — prepared for review

The V2 manifest plans 30 independent matched replicate blocks, each containing six treatment cells once, for 180 core episodes. Exactly 30 public ON/OFF matched pairs are planned. The block is the primary matching and inference unit; the 80 signal-phase rounds within an episode and the 180 episodes are not independent primary paired comparisons.

The primary per-episode outcome is the unchanged `public_signal_mapping_score`. For a completed public episode, count participation states from numerical bids over all 80 Stage-3 rounds. Score both KAPPA→A_ONLY/LAMBDA→B_ONLY and KAPPA→B_ONLY/LAMBDA→A_ONLY assignments, divide each count by all 80 rounds, and take the maximum. BOTH and NEITHER contribute to the denominator but neither mapping numerator. The primary block difference is public score with prior communication `True` minus the matched public score with prior communication `False`. The directional alternative is a positive mean block difference. Use an exact one-sided paired sign-flip test on the mean at alpha 0.05. Ties and zero differences remain in the sign-pattern count. Report the observed differences, complete-pair count (up to 30), mean, median, and exact one-sided p-value. The absolute-mean two-sided exact p-value is sensitivity only.

The exact calculation counts sign-flip sums on the integer 1/80 score-difference grid by dynamic programming. It yields mathematically the same tail count as enumerating all `2**n` sign vectors while avoiding `2**30` Python iterations. It also works for fewer than 30 complete pairs. Resample whole paired block differences 10,000 times with replacement for the 95% percentile interval, using the same frozen bootstrap seed `14018003554666323344` and linear quantiles. The exact p-value, not the bootstrap interval, is the primary decision statistic.

Failed and incomplete episodes retain their original manifest position. No partial rounds are spliced into another episode, and no replacement enters the 180-position primary manifest. Analyze completed public pairs only and label the primary dataset attrition-affected when a public pair is missing. Report an adverse directional worst-case bound over all 30 planned public pairs, assigning 0 to a missing prior-communication score and 1 to a missing no-prior score. These values are sensitivity assignments, not observed outcomes. An incomplete 180-episode dataset is labeled incomplete; interim analyses are partial/exploratory. There is no optional stopping or post-outcome alteration of order, signal paths, or sample size.

The secondary outcomes are: public-signal mutual information in bits, Stage-3 unique/both/neither participation rates, role balance, joint profit, joint regulator fines, and violation count. Calculate mutual information per episode from public signal and the four participation states, without pooling rounds. Compare six treatment cells descriptively and show within-block prior minus no-prior differences. Stage comparisons, agent text, adoption latency, persistence, and memo/plot narratives remain exploratory diagnostics, not substitutes for the primary test. The canonical metrics and derived table code are shared across versions; `episode_summary.csv` records batch, block, episode status, and episode outcomes for attempted positions, and `block_summary.csv` records batch, block, status, and paired differences for fully attempted blocks. After all 180 positions have been attempted, the tables contain 180 episode rows and 30 block rows.

# Notebooks

`run_episode.ipynb` invokes the manifest-aware episode CLI for an offline V2 dry run. Its execution flag is off by default. [analysis.ipynb](analysis.ipynb) reads the committed V2 results namespace, prepares descriptive summaries and plots, and leaves exports off by default. Scientific implementation and metric definitions live in `collusion_experiment`, not in notebook cells.

The analysis notebook also runs the exploratory V3 episode-level exact randomization test. From the repository root, install the package with `python -m pip install -e ".[analysis]"`; then run the notebook from the root or this directory. Its `PUBLIC_SIGNAL_BLOCKS = range(1, 21)` setting selects the 40 completed public-signal episodes; the test compares both possible signal-to-agent assignments within each episode and applies Holm adjustment across all 40 p-values. The results are in `public_signal_rows`, and an opt-in CSV export is available.

The notebook's `episode_rows` include `public_mapping_score` and `public_mutual_information_bits`. Mutual information describes association between the signal and all four bidding outcomes (Agent A alone, Agent B alone, both, neither); a high value does not by itself identify complementary turn sharing. The original prespecified paired earlier-communication test remains documented in the [V2 analysis plan](../docs/v2_confirmatory_analysis_plan.md). The episode-level test was added after some results had been inspected and is exploratory.
